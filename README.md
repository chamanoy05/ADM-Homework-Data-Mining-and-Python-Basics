# ADM-Homework-Data-Mining-and-Python-Basics
This repository contains the full submission for Homework of the Algorithmic Methods for Data Mining. This homework consists of solved coding challenges on HackerRank, covering Python Fundamentals, data structures, algorithms and libraries
## Repository Structure

The repository is structured according to the course submission guidelines as follows:

```text
├── README.md             # Homework documentation and project overview
├── problem1_scripts.py   # Python solutions for Problem 1 (HackerRank Domains)
```

Solved Challenges

## Problem 1: HackerRank Python Domains

The scripts.ipynb notebook contains solutions organized by the following domains:

• Introduction: Python syntax, control flow, loops, and basic functions.

• Basic Data Types: Lists, tuples, nested lists, and list comprehensions.

• Strings: String manipulation, text alignment, formatting, and string parsing.

• Sets: Set methods, mathematical set operations, and boolean checks.

• Collections: Advanced structures like Counter, defaultdict, namedtuple, OrderedDict, and deque.

• Date and Time: Date manipulation using the calendar and datetime modules.

• Exceptions: Error handling for values and division operations.

• Built-ins: Multi-dimensional sorting, zipped iteration, and sorting logic.

• Python Functionals: Functional tools including map() and lambda expressions.

• Numpy: Array transformations, matrix math, statistics, and linear algebra.
